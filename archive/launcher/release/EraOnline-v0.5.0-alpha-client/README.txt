ERA ONLINE - v0.5.0-alpha (Test Build)
=======================================

PLAYING
-------
  Run EraOnline.exe

  Play Online: enter the server IP and port 7777, then log in or register.
  Play Offline: single-player mode with a training dummy.

CONTROLS
--------
  W/A/S/D     Move
  E           Interact / Shop
  F           Pick up item
  I           Inventory
  C           Character panel
  L           Leaderboard
  Enter       Chat

NOTES
-----
  - This is an alpha test build. Expect bugs and missing features.
  - Report issues to the server host.
  - Settings (keybindings, volume, saved login) are stored in
      %APPDATA%\Godot\app_userdata\Era Online\settings.json

KNOWN LIMITATIONS
-----------------
  - Skills/magic system partially implemented
  - No clan or housing system yet
